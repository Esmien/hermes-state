# Живой блок прогресса установщика

Use when touching how `install.py` prints progress, or when the owner says the run
«льётся сплошным потоком» and wants it readable.

## Что требуется от вывода

Под заголовком текущего шага живёт блок последних строк (15–20, в зависимости от высоты
терминала). Новые строки появляются снизу, старые уходят вверх. Заголовок шага и
разделитель с таймером стоят на месте. При переходе к следующему шагу содержимое блока
стирается, а заголовок пройденного шага остаётся строкой в истории — так на экране
копятся только заголовки, а не весь лог.

Реализация — класс `Pane` в `install.py`; всё, что раньше печаталось через `print`,
идёт через `say()`/`step()`/`ok()`/`info()`/`warn()` и попадает в панель.

## Арифметика курсора (её легко сломать)

Кадр = `заголовок`, `разделитель`, `H` строк панели; после отрисовки курсор стоит на
последней строке панели, без перевода строки (перевод строки в конце кадра вызывает
прокрутку и уводит весь блок).

| Метод | Сдвиг вверх | Почему |
|---|---|---|
| `push()` | `H + 1` | возвращает на строку заголовка и перерисовывает кадр целиком |
| `begin()` | `H` | встаёт на строку разделителя, `\033[J` стирает разделитель+панель, заголовок прошлого шага остаётся выше |
| `finish()` | `H` | то же самое, но новый кадр не рисуется |

`H = max(6, min(18, rows - 14))`: запас нужен, чтобы кадр помещался в терминал вместе с
историей заголовков.

## Грабли

- **`\r` перед `\033[2K` обязателен.** `\033[2K` стирает строку, но не двигает курсор в
  начало: без `\r` каждая строка рисуется с колонки предыдущей, и заголовок вылезает
  обрезанным справа («==> С»).
- **Нельзя троттлить отрисовку, отбрасывая кадры.** Пачка вызовов в одном тике (шаг,
  который печатает 15 строк подряд) даёт на экране одну первую строку: последующие кадры
  отброшены и никогда не нарисуются. Либо рисуем каждый `push`, либо откладываем
  перерисовку с гарантией, что последний кадр всё равно будет показан.
- **Панель только при `sys.stdout.isatty()`.** Иначе — обычный построчный вывод:
  редирект в файл и CI не должны получать escape-последовательности. Аварийный выключатель
  — `NO_PANE=1`.
- **`push` без активного кадра печатает как обычную строку.** Иначе `\033[{H+1}A` уводит
  курсор в уже выведенный текст и перетирает его (так ломается финальная сводка после
  `finish()` и вывод шага `export`, где `step()` не вызывается).
- **Вывод дочерних процессов надо перехватывать.** `Popen(stdout=PIPE, stderr=STDOUT,
  text=True, bufsize=1)` + чтение построчно + `push` на каждую строку; `subprocess.run` с
  наследованием stdout отдаёт tty ребёнку, и панель не увидит ничего (`docker pull` будет
  рисовать мимо). Таймаут к такому `Popen` — `threading.Timer` с `proc.kill()`: у
  `run(timeout=…)` его не совместить с построчным чтением.
- **`die()` и конец `execute()` вызывают `finish()`.** Иначе трейсбек и итоговая сводка
  лягут поверх панели и оставят мусор.
- **bootstrap не должен заворачивать stdout установщика в `tee`.** Труба лишает `install.py`
  tty и панель отключается сама; `bootstrap.sh` логирует только свой stderr
  (`/var/log/vps-bootstrap.log`), а полный лог установщика идёт в
  `/var/log/vps-infra-install.log`.

## Как проверить отрисовку без экрана

Терминальный UI нельзя проверить глазами по логу — в файле видны только escape-байты.
Рабочий способ: запустить команду в настоящем псевдотерминале заданного размера, скормить
поток эмулятору терминала (`pyte`) и напечатать получившийся экран. Готовый прогон —
`scripts/pty-screen-dump.py`:

```bash
python3 scripts/pty-screen-dump.py --rows 34 --cols 110 --peak \
  -- python3 install.py --dry-run --only packages,users,secrets,verify
```

Что считается нормой на снимке: заголовки шагов идут строками подряд без дыр и обрывков,
под последним заголовком — разделитель с таймером и заполненная панель, справа ничего не
обрезано, после `finish()` на экране остаются только заголовки.

Минимальный тест самой панели без установщика (быстрее всего ловит ошибки арифметики):

```bash
python3 -c "import sys; sys.path.insert(0,'.'); import install; \
  install.PANE.begin('Тест'); [install.say(f'строка {i}') for i in range(1,9)]"
```

Прогнать его тоже через `pty-screen-dump.py`: все восемь строк обязаны быть видны.
