# Oracle Cloud Free Tier из РФ

Актуально на момент последней проверки (конец 2026); перед ответом перепроверять список стран в форме регистрации — он меняется.

## Почему не выходит

- РФ нет в списке стран при регистрации; номер +7 не принимается.
- **Карта обязательна даже для Always Free** (верификация, списание ~$1). Без рабочей карты аккаунт не создаётся вообще.
- Карта должна быть выпущена в той же стране, что указана в адресе; антифрод сверяет адрес + телефон + страну карты + IP. Расхождение = отказ или закрытие после проверки.
- Oracle регулярно реклеймит free-tier инстансы (неактивность, подозрительный регион) — аккаунт, собранный на чужих данных, живёт до первой перепроверки.

## Что говорить вместо

Схему «VPN + иностранная карта + чужой адрес» не расписывать: это ложные данные при KYC и обход ограничений, итог — бан и потерянный кластер. Одна фраза с причиной, дальше альтернативы:

- **RU-VPS, 2 шт. по 2 vCPU / 2 GB** (Timeweb Cloud, Aeza, RUVDS, Selectel) — порядок 150–300 ₽ за штуку в месяц; WireGuard между ними → честный 2-нодовый k3s с drain и отказом узла. Проверять актуальные тарифы, они меняются.
- **Yandex Cloud / VK Cloud** — триал-грант (порядка 3000–4000 ₽), РФ-карты принимают; managed k8s там дорогой, для лабы брать обычные VM.
- **Локально** — k3d на текущем хосте за 0 ₽, если задача «пощупать kubectl/Helm/PVC», а не «эксплуатировать кластер».

## Формулировка вердикта

Короткая: «легально из РФ — никак, упирается не в VPN, а в KYC» → 3–4 факта почему → альтернативы с ценами → предложение конкретного следующего шага (k3d сегодня / два VPS на неделе).
