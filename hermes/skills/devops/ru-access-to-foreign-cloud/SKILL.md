# Foreign cloud / SaaS from Russia

## When to use

«Как мне создать аккаунт X из России?», «где взять бесплатный VPS/кластер», «принимает ли Y РФ-карту», «как оплатить Z». Класс вопросов: **можно ли легально получить зарубежный сервис из РФ и что взять вместо него**.

## Procedure

1. **Сначала KYC, потом техника.** Проверь по справке провайдера: есть ли страна в списке при регистрации, принимается ли +7, требуется ли карта даже для free tier и должна ли она быть выпущена в стране адреса. VPN эту проверку не обходит — отвечать «через VPN можно» до этого шага значит соврать.
2. **Назвать факты прямо и без морализаторства.** Если регистрация требует неверных данных о стране/адресе/владельце карты — это ложные данные при KYC и обход санкционных ограничений. Отказаться давать пошаговую инструкцию **один раз**, с практической причиной (волны закрытия аккаунтов, потеря данных вместе с кластером), и сразу перейти к альтернативам. Владелец принимает отказ, когда причина практическая, и не принимает нотаций.
3. **Развернуть альтернативу с ценой.** Провайдеры, которые легально работают с РФ и дают ту же возможность: RU-VPS (Timeweb Cloud, Aeza, RUVDS, Selectel), Yandex Cloud / VK Cloud с триалом. Цены проверять на момент ответа, не по памяти.
4. **Предпочитать то, чем он управляет.** Свой дешёвый VPS сильнее бесплатного ящика гиперскейлера: его не отберут, и на интервью это «я поднимаю и эксплуатирую», а не «мне дали».

## Pitfalls

- Free tier гиперскейлеров реклеймят пачками за неактивность и несовпадение региона — на нём нельзя строить ничего, что жалко потерять (учебный кластер в том числе: он умрёт посреди подготовки).
- Managed k8s в Yandex/VK Cloud платный и дорогой относительно задачи «пощупать руками» — для лабы считать свои VPS, не managed.
- Не путать «сервис недоступен из РФ» с «сервис не обслуживает РФ»: первое лечится маршрутом, второе — только сменой провайдера.
